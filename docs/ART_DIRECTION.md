# Art direction — approved open terrain V3

The goal is a coherent, hand-painted-looking isometric FreeCol landscape whose biomes are distinguishable **at normal gameplay zoom**, with and without grid lines.

| Terrain | Accepted appearance |
| --- | --- |
| Grassland | Rich, deep, healthy green; dense continuous grassy vegetation with small flowers |
| Prairie | Golden-green long grasses, including subtle light-brownish-green areas |
| Savannah | Yellow-green, irregular grass tussocks, some exposed earth; vegetation density deliberately restrained |
| Plains | Muted dry olive/khaki green-brown; short fine grasses and exposed soil; retained warm revision |
| Desert | Pale warm sand; sparse scrub and stones; unmistakably sandy |

Principles:
1. Terrain types must be distinguishable as a set; don't evaluate an individual texture only in isolation.
2. Preserve approved families unless an actual in-game defect justifies reopening them.
3. No renderer or gameplay-rule changes.
4. Test both grid modes, mixed maps, and extreme continuous-biome stress maps.
5. Terrain should not dominate units, settlements and map features.
6. Resource-icon contrast (including tobacco on grassland) is deferred to a later resource-icon milestone.

Five variations per open terrain family, at native 128×64 and high-resolution 512×256 PNG sizes. Variations use the game's coordinate-dependent selection.
